# Wordflow

A privacy-first collection of eight everyday text tools. Built with React, Vite and Lucide icons. Text processing happens in your browser; there is no account, database or application server.

## Included tools

1. Text Diff Checker
2. Bulk Text Cleaner
3. Word & Character Counter
4. Duplicate Line Remover
5. Text Case Converter
6. PDF Text Line-Break Cleaner
7. Reading Time Calculator
8. Social Media Text Checker
